# The Board

A full-stack message board application where users can ask questions, share ideas, and participate in conversations.

## Live Demo

[The Board](https://message-board-blond.vercel.app/)

## Features

- User authentication
- Create and share messages
- View community conversations
- Interactive message board
- Responsive design
- Clean and modern UI

## Tech Stack

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend

- Node.js
- Express
- TypeScript
- MongoDB
- Mongoose

### Tools

- Git
- GitHub
- Vercel
- npm
